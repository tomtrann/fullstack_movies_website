# 🎬 Movie Web App

A movie discovery website built with React. Users can search for movies, browse popular movies, view movie details, and see trending searches. Trending searches are base on real user searching movies stored and updated in databases

## Features
- Search for movies
- Browse popular movies
- View movie details
- Pagination
- Trending movies based on search activity
- Responsive design

## Technologies
- FRONTEND:
- React
- Vite
- Tailwind CSS
- React Router

  External API:
- TMDB API

  BACKEND:
- Appwrite
